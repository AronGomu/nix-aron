Architecture design · Accepted

Transcript-safe silence cuts

FFmpeg proposes silent gaps. Timestamped words veto unsafe removals. Fixed handles retain 300 ms rhythm. Local STT evaluates progress without entering daily cutter runtime.

Core invariantRemove only audio-silent interval with zero protected-word overlap.
Pace invariantAccepted removal leaves 300 ms total gap.
Compatibility invariantNo new flags → old command behavior.

Retained gap: 300 ms total. Audio fade: 8 ms at join, fully inside silence. Video: hard cut.

  "retained_seconds": 0.300,
  "decision": "accepted",
  "reason": "audio_and_words_clear"
}

Malformed, negative, non-finite, reversed, unsorted times fail before encode. Times use source seconds.

Decision algorithm

for silence in detected_silences:
    proposed = trim_to_leave_total_gap(silence, keep=0.300)
    if proposed.duration <= safety_minimum:
        keep(silence, reason="nothing_safe_to_remove")
    elif overlaps(proposed, pad(words, word_padding)):
        keep(silence, reason="word_overlap")
    else:
        remove(proposed)
        fade_audio_at_join(0.008)
        hard_cut_video()

Failure modes

FailureResponse
GPU/CUDA load failsRun same pinned model/config on CPU. Record fallback.
Transcript JSON invalidAbort before encode. No partial output.
Word overlaps proposed removalVeto whole gap. Record word + reason.
Candidate transcript loses join wordReject candidate. Keep report evidence.
Audio join clicksReject; inspect handle/fade. Never increase fade into speech.
Source checksum changesStop. Preserve evidence. No overwrite recovery action.
Dirty repo ownership unclearStop before code edit/commit. User resolves staged state.

Residual limits

  • No visual-motion veto → silent screen action may compress.
