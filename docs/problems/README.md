## Entry format

Each report should contain:

1. Problem description + impact
2. Env + repro
3. Diagnostics + evidence
4. Fixes tried + result
5. Root cause
6. Final solution + code location
7. Verification
8. Apply/rollback cmds

Use one Markdown file per problem. Prefer symptom-based filenames.
