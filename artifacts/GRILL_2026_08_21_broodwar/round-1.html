Brood War on NixOS — what to actually install

"install me broodwar" has no single safe implementation: nixpkgs has no StarCraft package, the game data is Blizzard's and only reachable through a Windows installer under Wine, and the config repo can carry the runner in two different layers. Six decisions below; tick answers, add precision, hit copy, paste back.

Goal: Brood War on desk-main → Purpose → Game source → Wine runner → Config layer → MPQ handoff → Install run (later round)
1. What does "installed" have to mean when this is done?

The whole design tree hangs on this: a playable game needs a Wine stack and a desktop entry, while MPQ data for OpenBW needs neither once the files are extracted.

2. Which StarCraft do you have access to?

Nothing here can download the game for you without your Blizzard account, and Remastered vs classic changes both the installer path and which MPQ versions OpenBW gets.

3. Which Wine runner should the config carry?

This is the one thing that actually lands in nix-aron, and the three options differ in how much of the prefix work is scripted for you versus done by hand.

4. Which config layer: Home Manager or NixOS module?

The repo already splits these — user apps sit in home/aron/packages.nix, system-wide gaming bits in modules/nixos/gaming.nix (currently Steam only).

5. Should a launcher entry be created?

Your rofi launcher is fed by xdg.desktopEntries in home/aron/end4.nix; Lutris also creates its own entries imperatively, which is exactly the kind of state this repo tries to keep declarative.

6. How should the MPQs reach OpenBW?

Copies drift and eat ~1 GB twice; symlinks break if the prefix is rebuilt; env var keeps one source of truth but must be remembered per shell.
