1. Which packages exactly?

Lutris ships its own runners inside its FHS sandbox, so host Wine is optional — but without it you cannot poke the prefix, run wine from a terminal, or use winetricks outside Lutris.

2. Where should the prefix live?

This decides what OPENBW_MPQ_PATH will hardcode and how easy the MPQs are to find later; ~/Games does not exist yet, so either choice is a fresh directory.

3. Who drives the actual install?

Battle.net needs your account, your password and your 2FA; I can prepare and narrate, but I will not type your credentials, and an unattended install is not possible.

4. Where does OPENBW_MPQ_PATH get defined?

A session-wide variable is visible everywhere but bakes a game path into your login environment; a project-local one keeps the coupling inside the OpenBW workspace.

5. What does the launcher entry run?

The exec line only exists after the install (Lutris assigns the game slug), so this decides whether the entry ships in the same commit or a follow-up one.
