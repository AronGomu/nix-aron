1. Where should the brave-origin package come from?

Your locked nixpkgs-unstable (241313f) predates the package, so something must move before Origin can be installed at all.

2. Keep regular Brave installed alongside Origin?

Origin permanently removes Rewards, Wallet, Leo AI and VPN — if you ever need one of those, keeping Brave installed is the only escape hatch, at the cost of two browsers in the menu.

3. How should Origin get the declarative extensions?

Home Manager's programs.brave hardcodes the config dir per browser name, so pointing package at brave-origin would write the External Extensions JSONs into Brave-Browser — the dir Origin never reads. Your five extensions: Unhook, SponsorBlock, Enhancer for YouTube, Dark Reader, Floccus.

4. How far should the default-browser rewiring go?

"Default browser" spans 87 brave references across 6 files: mime handlers in desktop.nix, BROWSER=brave in shell.nix, browser = "brave" in Hyprland's variables.lua, ~60 rofi launcher entries in end4.nix, and the brave-personal / brave-mtgones aliases.

5. How should the current Brave settings reach Origin?

"Duplicate all settings" can mean a byte-for-byte profile clone or a sync-level copy — they carry very different things. The copy is one-time and one-way: changes made in Origin afterwards never flow back.

6. Which profiles should be copied?

You run two: Default (brave-personal) and Profile 1 (brave-mtgones). Copying both keeps the alias flags working unchanged.

7. Who runs the profile copy, and when?

The copy must happen with Brave fully closed, otherwise you clone half-written databases. It writes ~1.8 G into a new directory and never modifies the source — but it is a data operation outside Nix, so I will not start it without your say-so.
