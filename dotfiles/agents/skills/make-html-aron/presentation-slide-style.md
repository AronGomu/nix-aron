# Presentation Slide Style

## Input

(Optional) DESIGN.md | BRAND.md document

## DONT => INSTEAD

Scroll Snap => Free scroll, keep distinct slides
Justified left content => Centered by default
Leave free space => Use slide real-estate
No image if enough space => add 1/2/... image(s)
Information for presentator (notes, checklist, CTA, ...) => Remove
