Research Report · NixOS · GNOME Files

Video thumbnail previews in Nautilus

Nautilus never decodes video itself. It runs external *.thumbnailer programs discovered on XDG_DATA_DIRS. On this host only font/PDF thumbnailers were registered — no video handler — so icons stayed blank.

1 How it works

Video file
→
Nautilus
→
gnome-desktop factory
→
.thumbnailer match
→

→
PNG cache

Factory scans $XDG_DATA_HOME/thumbnailers then system data dirs. Exec placeholders: %i path, %u URI, %o out, %s size. Cache: ~/.cache/thumbnails/{normal,large,...}. Failures land in ~/.cache/thumbnails/fail/gnome-thumbnail-factory/.

4 Failure modes

IssueSevCause → fix
No video thumbs after GNOME core-apps swap high Totem gone; Showtime has no .thumbnailer → install ffmpegthumbnailer
.thumbnailer invisible high Not on XDG_DATA_DIRS → system/HM packages + re-login
Fail cache poisoned high Prior fails stored → rm -rf ~/.cache/thumbnails/*
Decode fail / missing codec med ffmpeg build flags / gst plugins → test CLI; totem path pulls gst-libav
bwrap / userns sandbox med Hardened kernel / missing bubblewrap → ensure bwrap + userns
Flatpak Nautilus med Can't see host store thumbnailers → system Nautilus preferred
Thumbs disabled in settings low org.gnome.desktop.thumbnailers disable-all or Nautilus never

5 Verify

  1. Rebuild / switch
    Apply HM/NixOS so ffmpegthumbnailer lands on profile + XDG data dirs.
  2. Confirm registration
    ls ~/.nix-profile/share/thumbnailers or scan $XDG_DATA_DIRS/*/thumbnailers for ffmpegthumbnailer.thumbnailer.
  3. CLI smoke test
    ffmpegthumbnailer -i video.mp4 -o /tmp/t.png -s 256 && file /tmp/t.png
  4. Clear poison cache
    nautilus -q; rm -rf ~/.cache/thumbnails/*
  5. Open folder in grid view
    Local videos only first. PNGs should appear under ~/.cache/thumbnails/large/ or normal/.
Bottom line One package: ffmpegthumbnailer. Already added to home/aron/packages.nix. Rebuild, wipe thumb cache, reopen Nautilus.
