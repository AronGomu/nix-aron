Tool choice

Job Tool Why this one
Silence cut auto-editor via your remove-silence already pinned + tuned, no reason to touch
Transcript faster-whisper large-v3 (CTranslate2) best FR accuracy per GPU-second, runs on the 5060 Ti
Word timestamps WhisperX forced alignment (wav2vec2 voxpopuli_base_10k_asr_fr) whisper's own timestamps drift ±0.3s; wav2vec2 alignment is per-word, ~10 ms — that precision is what makes mid-sentence retake splits possible
Retake logic custom DP alignment vs your script + rapidfuzz guards no off-the-shelf tool does "keep the last take"; needs script anchoring
Cutting ffmpeg trim/atrim + concat (x264 or h264_nvenc) frame-accurate, cuts fall between words

Rejected: LLM-on-transcript retake detection (no reliable timestamps, non-deterministic, expensive per re-run); pure audio self-similarity (misses reworded retakes); Resolve auto-cut (manual).

The pipeline

retake-pipeline "raw.mov" "script.md"                 # silence -> transcribe -> plan -> render
retake-pipeline "raw.mov" "script.md" --plan-only     # stop at report.md, review first
retake-pipeline "raw.mov" "script.md" --duration 180  # test window
retake-pipeline "raw.mov" "script.md" --nvenc         # GPU encode

Files live in /home/aron/projects/retake-cut/ (retake_cut.py, retake-cut launcher, retake-pipeline, README.md, .venv). Artifacts per video go to <stem>-retake/: nosilence.mov, words.json, plan.json, report.md — all reused on re-run, so re-tuning the cut logic costs seconds.

How retakes are found

Spoken words are aligned to the script with a DP whose moves are: match, mismatch, improvised word, skipped script word, and jump (restart anywhere, fixed penalty). A backward jump = a retake. Words between jumps form a take covering a script range; every script position is then kept only from its last take, so an earlier take is truncated at the exact word where a later one resumes the script — a retake that restarts mid-sentence cuts mid-sentence. Improvisation is absorbed as unmatched words inside a take, so drifting from the script does not trigger a cut.

Over-cut guards: replacement take needs ≥3 matched script words; dropped span and replacement must be ≥55 similar; a take still running at the end of the analysed window can never supersede (it is only half-said); a separate pass catches immediate stutters too short for the DP.
