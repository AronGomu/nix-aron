Verbatim ASR — your diagnosis was right

The proof

Whisper is trained on human-made captions. Captions are cleaned: no stutters, no false starts, fixed grammar. So the model learned to produce clean text, not true text. It is doing exactly what it was trained to do, and that behaviour cannot be turned off with decoding flags — it lives in the weights, not the sampler.

Ran the same audio through a CTC model (wav2vec2, no language model, no rewriting — emits phonemes frame by frame). Side by side:

Those two retakes match exactly the "speech energy with no words on it" gaps I measured earlier (43.80–44.90s, 62.00–62.50s). The cutter never had a chance: the words were not in its input.

What I recommend: two transcripts, different jobs

Do not replace Whisper. Add CTC and let each do what it is good at.

audio
 ├─ whisper large-v3  ──►  readable text, punctuation, proper nouns   ──►  report + script alignment
 └─ wav2vec2 CTC      ──►  verbatim stream + phonetic features        ──►  retake DETECTION
                                                                            └─ merged drop list

Three detectors on the CTC side, all local, all free:

  • D1 coverage gap — speech energy with no Whisper word on it → re-decode that span with CTC → if it phonetically matches neighbouring text, it is a swallowed retake. Catches the 43.8s and 62.0s cases.
  • D2 phonetic self-similarity — the table above. Catches repeats even when CTC spells them wrong (tuprix / tu prix).
  • D3 CTC-vs-Whisper diff — spans where CTC emits substantially more syllables than Whisper. Direct measure of "Whisper compressed something here".

Guard against the false positive: a candidate whose repetition also exists in the written script is rhetorical → never auto-cut, mark review.

Order of work

  1. Add retake-cut ctc — verbatim transcript + frame features cached next to words.json. (no new dependency)
  2. D1 gap recovery → new drop candidates merged into plan.json. Highest value per line of code.
  3. D2 phonetic self-similarity as a second detector, tagged review not auto.
  4. Swap in bofenghuang/wav2vec2-FR-7K-large if CTC spelling noise hurts D3.
  5. Re-run the 3-min example pair in the skill so the before/after reflects the new catches.

Step 1+2 is where the missing retakes live. Say go and I start there.
