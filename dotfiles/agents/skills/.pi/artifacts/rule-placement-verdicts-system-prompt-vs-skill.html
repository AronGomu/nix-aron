Placement verdict per rule — system prompt vs triggerable skill

Test used, in order:

  1. Can it fire with no skill loaded, in a random session? No → skill.
  2. Does breaking it cost data, history, secrets, or user trust? Yes → system prompt, even if verbose.
  3. Does stating it cost more than 2 caveman-lite lines? Yes → system prompt keeps the invariant, skill keeps the procedure (hybrid).
  4. Is it a workflow contract between orchestrator and children? Yes → skill/role file.

Verdicts: SYS = APPEND_SYSTEM.md · SKILL = stays where it is · HYBRID = one-line invariant in SYS, procedure in skill.
